program 2> file.txt и program 2>> file.txt работают с потоком ошибок, подходят.
program << file.txt - он не создаёт файл и не записывает ошибки.
program file.txt <2 - это ввод, а не вывод.
program < file.txt - он читает, а не создает и не записывает туда ошибки.
program >> file.txt - перенаправляет обычный ввод, а не ошибки.
