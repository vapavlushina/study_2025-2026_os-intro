Выполнение подраздела 1.4 Terminal: основы

Термин - понятие или слово. Ассоль- имя героини из книги “Алые паруса”. А всё остальное - подходит.

Команды PWD не существует. Есть лишь pwd.

ls –almost-all –human-readable -l /some/directory - верно, та же запись, только более развёрнутая. ls –human-readable -A -l /some/directory - порядок не важен, эквивалентна. ls -lah /some/directory - не эквивалентна, т.к. показывает всё, включая “.” и “..”. ls –all -h -l /some/directory - не эквивалентна, т.к. показывает “.” и “..”. ls -Ahl /some/directory - порядок внутри не важен, эквивалентна.

Все варианты верные. ls ../Downloads и ls ./../Downloads - относительный путь. ls ~/Downloads - через тильду. ls /home/bi/Downloads - абсолютный путь.

mkdir - создаёт директорию . rm -r - удаляет. mv - перемещает. mkdir -r - mkdir не имеет опции -r, такой команды не существует.

program 2> file.txt и program 2>> file.txt работают с потоком ошибок, подходят. program << file.txt - он не создаёт файл и не записывает ошибки. program file.txt <2 - это ввод, а не вывод. program < file.txt - он читает, а не создает и не записывает туда ошибки. program >> file.txt - перенаправляет обычный ввод, а не ошибки.
